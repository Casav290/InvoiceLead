# InvoiceLead

Logiciel de facturation en ligne pour indépendants et PME, de la famille Lead (Scanlead, CRMlead, ProjectLead). Premier marché : la Suisse (QR-facture, TVA suisse, relances, rapprochement bancaire camt).

Le projet est en phase de cadrage. Le plan de développement se trouve dans [docs/PLAN.md](docs/PLAN.md).
